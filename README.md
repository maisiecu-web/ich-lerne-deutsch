# Ich learne Deutsch

*Alright, ladies and gentlemen. I have turned myself and German grammar into a bit.*

My German self-study programme, from zero to the Goethe-Zertifikat B1, following *Grammatik aktiv A1–B1* chapter by chapter.

- A day-by-day calendar in seven acts, with rest days, breaks and level tests
- Every chapter has an explanation, a joke, new vocabulary, and exercises (typed answers, multiple choice and sentence building)
- Vocabulary drills with spaced repetition, a box for every mistake, and a cheat sheet
- **Das Grammatik-Kabarett:** every grammar rule gets a character and a running joke, with 85 sketches plus 85 jokes written in German
- **Karteikarten:** flip flashcards for vocabulary, example sentences, grammar rules, sketches and German jokes
- A back button, a jump-to-today button, and a book reader with zoom
- A live countdown to exam day

The page is password-locked: the content is encrypted and only opens with the password.
